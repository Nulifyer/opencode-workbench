# Harness capability matrix

Status terms:

- **Supported**: proven by current code plus deterministic or real contract test.
- **Mapped**: a transport/surface exists, but full semantic parity is not proven.
- **Missing**: the recorded contract has no representation.
- **Unknown**: evidence would require a later spike or explicit provider call.

The ACP column is pinned to OpenCode `1.18.15`, ACP SDK `0.21.0`, protocol `1`.
AHP/native columns are discovery status only; there is no production native mode.

## Discovery conclusion

ACP `1.18.15` is strong enough to justify later mapping work for session setup,
selection, persistence, and slash commands. It is not yet sufficient to replace
stable HTTP/SSE mode. The recorded contract is missing queue/steer/follow-up and
delete semantics, and provider-free evidence cannot establish exact permission,
question, tool, diff, usage, or settlement behavior. Production ACP and AHP work
therefore remains dependency-blocked on later discovery/ADR issues.
